# 强化学习概述
  强化学习(Reinforcement Learning,RL)讨论的问题是智能体如何在复杂且不确定的环境中最大化它能获得的奖励。在强化学习过程中，智能体会与环境一直交互。智能体在环境中获得某个状态后，它会利用该状态输出一个动作，这个动作也被称为决策。然后这个动作会在环境中被执行，环境会根据智能体采取的动作，输出下一个状态以及当前这个动作带来的奖励。智能体的目的就是尽可能多地从环境中获得奖励。

## 强化学习与监督学习
  监督学习(Supervised Learning)：在这个过程中，有两个**假设**：
- 输入数据没有关联，否则学习器不好学习。
- 学习器需要知道正确的标签来修正自己的预测。

  然而，这两个假设在强化学习都不能满足。强化学习中，学习的输入的样本是序列数据，并且没有非常强的监督者，只有奖励信号，且奖励信号是延迟的。

## 序列决策
<img width="1879" height="849" alt="1 18" src="https://github.com/user-attachments/assets/875d3890-97ef-43c9-bb7a-49041ec2b7f0" />
序列决策(sequential decision making)：在一个强化学习环境中，智能体的目的就是选取一系列的动作来最大化奖励。但是在这个过程中，奖励会被延迟。
在与环境的交互过程中，智能体会获得很多观测，智能体会采取一个动作，也会得到一个奖励，所以历史是观测，动作，奖励的序列：

```math
H_t = o_1, a_1, r_1, \ldots, o_t, a_t, r_t
```

智能体在采取当前动作时会依赖它之前的历史，所以我们可以把整个状态看成关于这个历史的函数：

```math
S_t = f(H_t)
```

但是有一种情况是智能体得到的观测不能包含环境运作的所有状态，因为在强化学习的设定里面，环境的设定才是真正的所有状态。当智能体只能看到部分的观察测，我们就称这个环境是部分可观测的(Partially observed)。在这种情况下，强化学习通常被建模成部分可观测马尔可夫决策过程(partially observable Markov decision process, POMDP)的问题。部分可观测马尔可夫决策过程是马尔可夫决策过程的一种泛化。 部分可观测马尔可夫决策过程依然具有马尔可夫性质，但是假设智能体无法感知环境的状态，只能知道部分观测值。

## 强化学习智能体的组成成分和类型
### 策略
  智能体用策略来选取下一步的动作。策略本质是一个函数，用来把输入的状态变成动作。策略可以分为两种：随机性策略和确定性策略。
- 随机性策略(stochastic policy)就是$\pi$函数，也就是：
```math
\pi(a \mid s) = p(a_t = a \mid s_t = s)
```
输入一个状态$s$，输出一个概率，这个概率是智能体所有动作的概率，然后对这个概率分布进行采样，可得到智能体将采取的动作。
- 确定性策略(deterministic policy)就是智能体直接采取最有可能的动作，即：
```math
a^* = \arg\max_{a} \pi(a \mid s)
```

  通常情况下，强化学习一般使用随机性策略。
### 价值函数
  价值函数的值是对未来奖励的预测，我们用它来评估状态的好坏。价值函数中有一个**折扣因子**(discount factor)，我们希望在尽可能短的时间内得到尽可能多的奖励。
  价值函数的定义为：
```math
V_\pi(s) \doteq \mathbb{E}_\pi[G_t \mid s_t = s]
= \mathbb{E}_\pi\left[\sum_{k=0}^{\infty} \gamma^k r_{t+k+1} \,\middle|\, s_t = s\right],
\quad \text{对于所有的 } s \in S
```
  期望的下标是$\pi$函数，这个值可以反映我们在使用策略$\pi$的时候，到底可以获得多少奖励。
  还有一种价值函数：Q函数。Q函数中包含两个变量：状态和动作。其定义为：
```math
Q_\pi(s,a) \doteq \mathbb{E}_\pi[G_t \mid s_t = s,\, a_t = a]
= \mathbb{E}_\pi\left[\sum_{k=0}^{\infty} \gamma^k r_{t+k+1} \,\middle|\, s_t = s,\, a_t = a\right]
```
### 模型
  模型决定了下一步的状态。下一步的状态取决于当前的状态以及当前采取的动作。它由状态转移概率和奖励函数两个部分组成。状态转移概率即：
```math
p_{ss'}^{a} = p(s_{t+1} = s' \mid s_t = s,\, a_t = a)
```
  奖励函数是指我们在当前状态采取了某个动作，可以得到多大的奖励，即：
```math
R(s,a) = \mathbb{E}[r_{t+1} \mid s_t = s,\, a_t = a]
```

  当我们拥有了策略，价值函数和模型三个部分，就形成了一个马尔可夫决策过程(Markov decision process)。

## 强化学习智能体的类型
  根据智能体学习的事物不同，我们可以把智能体归类。基于价值的智能体显式学习价值函数，隐式学习它的策略，策略是从学到的价值函数中推算出来的。基于策略的智能体直接学习策略，我们给他一个状态，它就会输出对应动作的概率，基于策略的智能体并没有学习价值函数。把基于价值的智能体和基于策略的智能体结合起来就有了演员-评论员智能体。这一类智能体把策略和价值函数都学习了，然后通过两者的交互得到最佳的动作。

  基于策略和基于价值的强化学习方法区别：基于策略：直接优化策略 \(\pi(a\mid s)\)，让智能体获得更高的期望累计回报。代表方法是策略梯度。
基于价值：估计动作价值 \(Q(s,a)\)，即在状态 \(s\) 采取动作 \(a\) 后的期望回报，再用这些估计指导选择。代表方法是 Q-learning、Sarsa。
Actor-Critic 结合了两者：Actor 用策略选动作，Critic 估计价值，为策略更新提供信号。

另外，我们可以通过智能有没有学习环境模型来对智能体进行分类。有模型(model-based)强化学习智能体通过学习状态的转移来采取动作。免模型(model-free)强化学习智能体没有去估计状态转移等，它通过学习价值函数和策略函数进行决策，免模型强化学习智能体中没有环境转移的模型。
我们可以用马尔可夫决策过程来定义强化学习任务，并将其表示为四元组 <S,A,P,R>，即状态集合、动作集合、状态转移函数和奖励函数。如果这个四元组中的所有元素都已知，且状态集合和动作集合在有限步数内是有限集，那智能体可以对真实环境进行建模。

## 学习与规划
  一个常见的策略是，先学习环境如何工作，也就是了解环境工作的方式，即学习得到一个模型，然后利用这个模型进行规划。
